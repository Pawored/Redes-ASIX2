### 1. Dos webs estáticas, misma IP y puerto 80
$ curl -s http://web1.asir.local/ | grep "<h1>"
    <h1>Web estática 1</h1>
$ curl -s http://web2.asir.local/ | grep "<h1>"
    <h1>Web estática 2</h1>
$ curl -s -H "Host: web2.asir.local" http://127.0.0.1/ | grep "<h1>"   # misma IP, cambia solo la cabecera Host
    <h1>Web estática 2</h1>
$ curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1/   # acceso por IP -> default_server
000
(000 = conexión cerrada por 'return 444')

### 2. Zona protegida
$ curl -sI http://web1.asir.local/privado/
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Basic realm="Zona restringida - ASIR"
$ curl -s -o /dev/null -w "%{http_code}\n" -u alumno:malapass http://web1.asir.local/privado/
401
$ curl -s -u alumno:Asir2026 http://web1.asir.local/privado/ | grep "<h1>"
  <h1>Zona protegida</h1>
$ curl -s -o /dev/null -w "%{http_code}\n" http://web1.asir.local/.htpasswd
403

### 3. Web PHP
$ curl -s "http://php.asir.local/?nombre=ASIR" | grep -E "<h1>|<li>"
  <h1>Hola, ASIR</h1>
    <li>Fecha y hora del servidor: 16/11/2026 16:11:46</li>
    <li>Versión de PHP: 8.3.6</li>
    <li>Servidor web: nginx/1.24.0</li>
    <li>Interfaz (SAPI): fpm-fcgi</li>
    <li>Tu IP: 127.0.0.1</li>
$ curl -s "http://php.asir.local/?nombre=<script>alert(1)</script>" | grep "<h1>"   # XSS neutralizado
  <h1>Hola, &lt;script&gt;alert(1)&lt;/script&gt;</h1>
$ curl -s http://php.asir.local/info.php | grep -o "<title>.*</title>"
<title>PHP 8.3.6 - phpinfo()</title>
$ curl -s -o /dev/null -w "%{http_code}\n" http://php.asir.local/noexiste.php
404
